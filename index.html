            Your data: how saving and backups work

            Your data is saved automatically. Everything you add stays in this browser on this device. There is no server and no account, so you do not need to import anything each time. Just open iPlan again in the same browser and the same address, and it's all there.

            When could data disappear? If you clear browsing/site data, use a private or incognito window, switch to a different browser or device, or open iPlan from a different address (the file on your computer and the GitHub Pages link keep separate data).

            1. Back up: press Export backup. A file named iplan-backup-DATE.json downloads to your computer. Do this every week or so, and always before clearing browser data.
            2. Restore or move to another device: press Import backup, choose that file, and confirm. It replaces what's currently in iPlan. (To move devices, send the file to yourself first.)

            Privacy: iPlan has no tracking and makes no network requests, so your notes never leave your device. Backup files are plain text, so keep them somewhere private. On a shared computer, erase your data when you finish.
